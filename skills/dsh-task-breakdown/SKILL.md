# 任务拆解

## 流程

1. **验收标准先行**：把"做完"定义为可验证的检查项（命令输出、文件存在、行为符合）
2. **拆子任务**：每项 30 分钟内可完成、可独立验证
3. **依赖排序**：先做被依赖的；无法排序说明拆得不够
4. **写进 todo 工具**：每项一个条目，完成即勾
5. **防范围蔓延**：过程中冒出的新需求记入 backlog，不混入当前任务

## 执行纪律

- 先跑通"最小闭环"（端到端最简路径），再补边角
- 每完成一个子任务就验证，不等最后
- 受阻时记录阻塞点与已尝试的方案，而不是换方向
