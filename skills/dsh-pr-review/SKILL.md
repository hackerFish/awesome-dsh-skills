# PR 审查

## 审查前

- 自己先过一遍：测试通过、无密钥、无调试残留
- PR 单一目的：一个 PR 只解决一个问题；范围过大先要求拆分

## 检查清单

1. 行为：改动是否实现描述；边界条件是否覆盖
2. 安全：输入校验、密钥、权限
3. 兼容：是否影响其他调用方；DSH 版本是否标注
4. 测试：关键路径覆盖；测试是否测行为
5. 文档：README/CHANGELOG 是否同步

## 反馈格式

```
文件:行号 | 严重级(阻断/建议/吹毛求疵) | 事实 | 建议
```

- 只陈述可复现的事实，不评价作者
- 非阻断的琐碎问题合并为一条，避免刷屏
- 拿不准的标"需讨论"
